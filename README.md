## Требования к системе

- Docker
- Docker Compose
- Node.js 20.12.2 (для локальной разработки)

## Установка и запуск

# Установка зависимостей
```bash
make setup
```

# Запуск в режиме разработки
```bash
make dev
```

# Запуск тестов
```bash
make test
```
